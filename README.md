# Генератор официальных отчетов в Google Sheets (Word-макет в Excel)

Интерактивное настольное приложение на Python (Tkinter) для симуляции и экспорта презентабельных корпоративных отчетов прямо в **Google Sheets**.

Отчет строится по стандартам официального документа (как бланк в Word):
- Официальный колонтитул и гриф утверждения документа.
- Главный титульный блок с номером, датой и ответственным лицом.
- Информационный паспорт документа.
- **4 стилизованные карточки ключевых показателей (KPI)**: общий оборот, количество сделок, средний чек и процент выполнения плана с мягкой цветовой заливкой и контрастными акцентами.
- **Детализированный реестр хозяйственных операций**: с чередующейся заливкой строк («зебра»), точным форматированием валют (`₽`), статусами и центрированием.
- **Формулы Google Sheets**: автоматический пересчет итогов (`=SUM(...)`).
- **Заключительные положения и блок подписей** сторон с местом для печати.
- Автоматическая настройка ширин колонок, высоты строк и закрепление шапки таблицы.

## 🔒 Безопасность и хранение секретов

JSON-файл сервисного аккаунта Google Cloud содержит приватный ключ (`private_key`), обеспечивающий доступ к Google Sheets API от лица сервисного аккаунта. Для обеспечения безопасности соблюдайте следующие правила:

1. **Исключение из контроля версий (Git)**:
   - Файлы ключей авторизации добавлены в `.gitignore` и **ни в коем случае не должны попадать в публичные или общие репозитории**.
   - В репозитории предоставлен безопасный шаблон-образец `credentials.example.json`, демонстрирующий формат файла без реальных секретов.

2. **Настройка авторизации**:
   - Создайте сервисный аккаунт в [Google Cloud Console](https://console.cloud.google.com/) с доступом к **Google Sheets API** и **Google Drive API**.
   - Создайте и скачайте ключ авторизации в формате JSON (*IAM & Admin* → *Service Accounts* → *Клик по аккаунту* → *Keys* → *Add Key* → *Create new key* → *JSON*).
   - Поместите скачанный JSON-файл в корень проекта (клиент автоматически обнаружит его) **или** укажите путь к нему через системную переменную окружения `GOOGLE_APPLICATION_CREDENTIALS`:
     ```bash
     set GOOGLE_APPLICATION_CREDENTIALS=C:\path\to\your_service_account.json
     ```

3. **Локальные конфигурации**:
   - Файл `app_config.json`, хранящий ID последней открытой таблицы и локальные настройки интерфейса, также игнорируется Git.

## 🚀 Быстрый запуск

1. Установите зависимости проекта:
   ```bash
   pip install -r requirements.txt
   ```
2. Запустите приложение через файл **`run_app.bat`** (двойным кликом в Windows) или через консоль:
   ```bash
   python app.py
   ```

## 📋 Как пользоваться

1. **Предоставление доступа сервисному аккаунту**:
   - При запуске приложение считает ключ и выведет email вашего сервисного аккаунта (например: `your-bot@your-project.iam.gserviceaccount.com`).
   - Нажмите кнопку **«📋 Скопировать email»**.
   - Откройте нужную Google Таблицу в браузере, нажмите кнопку **«Настройки доступа» (Share)** и добавьте скопированный email с ролью **«Редактор»**.

2. **Параметры отчета**:
   - Вставьте **ID таблицы** (или полную ссылку из адресной строки браузера).
   - Выберите **диапазон дат** (вручную или с помощью быстрых кнопок: *«Текущий месяц»*, *«Прошлый месяц»*, *«Текущий квартал»*, *«Случайные 30 дней»*).
   - Выберите **подразделение / департамент** и укажите ФИО составителя.
   - Задайте **количество операций** (от 5 до 40).
   - При необходимости нажмите **«🎲 Случайные параметры»** для генерации демонстрационных данных в 1 клик.

3. **Предпросмотр и экспорт**:
   - Нажмите **«👁️ Предпросмотр данных»**, чтобы ознакомиться с операциями во встроенной интерактивной таблице.
   - Нажмите **«🚀 Сформировать и отправить отчет в Google Sheets»**.
   - После завершения нажмите **«🌐 Открыть таблицу в браузере»** для перехода к готовому документу.

## 📁 Структура файлов

- `app.py` — графическое приложение на Tkinter / ttk с асинхронной обработкой потоков.
- `report_generator.py` — движок симуляции данных и глубокого форматирования документа через Google Sheets API v4 (`batchUpdate`, `mergeCells`, `repeatCell`, `updateDimensionProperties`).
- `google_sheets_client.py` — клиент для работы с Google Sheets API.
- `google_sheets.py` — алиас модуля для обратной совместимости.
- `credentials.example.json` — безопасный шаблон структуры JSON-ключа авторизации.
- `requirements.txt` — внешние зависимости проекта.
- `run_app.bat` — скрипт быстрого запуска приложения без открытия консоли.
- `app_config.json` — локальный файл кэша настроек (создается автоматически, игнорируется Git).
